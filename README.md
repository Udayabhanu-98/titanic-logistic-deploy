# 🛳️ Titanic Survival Prediction – Logistic Regression + Streamlit Deployment

This project predicts the survival of passengers aboard the Titanic using a **Logistic Regression** model. The model is trained on a cleaned Titanic dataset and deployed as an interactive web application using **Streamlit**.

---

## 🔍 Features

- Binary classification using Logistic Regression.
- Performed data cleaning, feature encoding, and scaling.
- Used columns like `Pclass`, `Sex`, `Age`, `Fare`, `Embarked`, etc.
- Deployed a real-time prediction app using Streamlit.
- Displayed performance metrics including accuracy, F1 score, and ROC AUC.

---

## 🧠 Model & Deployment Overview

- Model: `LogisticRegression()` from Scikit-learn
- Scaler: `StandardScaler()`
- Deployment: **Streamlit** on **Render.com**
- Final metrics:
  - Accuracy: `84.9%`
  - Precision: `83.9%`
  - Recall: `78.8%`
  - F1 Score: `81.2%`
  - ROC AUC Score: `87.9%`
